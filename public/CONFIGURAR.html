⚠️ Configuração Necessária

❌ O jogo não funciona ainda!
Você fez deploy apenas do frontend (interface).
Falta fazer deploy do backend (servidor WebSocket).

🎯 O Que Você Precisa Fazer

📍 PASSO 1: Deploy do Servidor WebSocket

O servidor de jogo precisa rodar em um serviço separado que suporte WebSocket.

Recomendado: Render.com (100% grátis)

  1. Acesse render.com
  2. Faça login/cadastro (pode usar GitHub)
  3. Clique em "New +" → "Web Service"
  4. Conecte este repositório do GitHub
  5. Configure:
    • Name: carbattle-server
    • Environment: Node
    • Build Command: npm install
    • Start Command: node server/index.js
    • Plan: Free
  6. Clique em "Create Web Service"
  7. ANOTE A URL! Algo como: https://carbattle-server-xxxx.onrender.com

⏱️ Aguarde cerca de 5 minutos para o deploy completar

📍 PASSO 2: Configure a URL no index.html

Edite o arquivo index.html (ou netlify-deploy/index.html):

<script>
  // Descomente e configure com a URL do Render:
  window.WS_SERVER_URL = 'wss://carbattle-server-xxxx.onrender.com';
</script>

⚠️ IMPORTANTE:

  • Use wss:// (não https://)
  • Copie a URL exata do Render
  • Não esqueça o ; no final
📍 PASSO 3: Faça Deploy Novamente

Depois de configurar o index.html:

  • Netlify: Arraste a pasta netlify-deploy novamente
  • OU faça commit e push para o GitHub (se conectado via Git)

✅ Checklist

  • ☐ Backend deployado no Render
  • ☐ URL do servidor anotada
  • ☐ index.html configurado com WS_SERVER_URL
  • ☐ Deploy atualizado no Netlify
  • ☐ Testado e funcionando!

💡 Por Que Isso é Necessário?

O Netlify serve apenas arquivos estáticos (HTML, CSS, JS). Ele não pode executar servidores Node.js ou WebSocket.

Por isso, você precisa:

  • Netlify: Para o frontend (interface do jogo)
  • Render/Heroku/Railway: Para o backend (lógica multiplayer)
🎮 Depois de configurar, o jogo vai funcionar perfeitamente!
Multiplayer em tempo real, mobile e desktop, tudo grátis! 🚀
