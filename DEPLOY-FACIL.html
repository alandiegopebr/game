🚀 Deploy Simplificado - CarBattle Arena

Siga estes passos e seu jogo estará online em ~10 minutos!

📋 Checklist Rápido

  • ☐ Deploy do servidor no Render (~5 min)
  • ☐ Configurar URL no index.html (~1 min)
  • ☐ Deploy do frontend no Netlify (~2 min)
  • ☐ Testar e jogar! 🎮

PASSO 1: Deploy do Servidor (Backend)

1Clique no botão abaixo para fazer deploy automático:

🚀 Deploy no Render.com

2No Render, conecte este repositório:

https://github.com/alandiegopebr/game

Se não aparecer, clique em "Configure account" e autorize o GitHub.

3Configure o serviço:

  • Name: carbattle-server (ou qualquer nome)
  • Environment: Node
  • Build Command: npm install
  • Start Command: node server/index.js
  • Plan: Free (deixe selecionado)

4Clique em "Create Web Service"

Aguarde ~3-5 minutos para o deploy completar.

✅ Quando terminar:
A URL do servidor aparecerá no topo da página.
Exemplo: https://carbattle-server-xyz123.onrender.com

📋 COPIE ESTA URL! Você vai precisar no próximo passo.
⚠️ Importante: Você pode verificar se o servidor está funcionando abrindo a URL no navegador. Deve mostrar "✅ Servidor Online".

PASSO 2: Configurar o Frontend

1Abra o arquivo: netlify-deploy/index.html

2Procure por esta linha (~linha 18):

// window.WS_SERVER_URL = 'wss://seu-servidor-websocket.com';

3Descomente e substitua pela URL do Render:

window.WS_SERVER_URL = 'wss://carbattle-server-xyz123.onrender.com';
⚠️ ATENÇÃO:
  • Troque https:// por wss://
  • Use a URL EXATA que você copiou do Render
  • Não esqueça o ; no final

4Salve o arquivo!

PASSO 3: Deploy do Frontend

1Acesse o Netlify:

🌐 Abrir Netlify Drop

2Arraste a pasta netlify-deploy para o Netlify

A pasta está na raiz do projeto. Arraste e solte na área indicada.

3Aguarde o upload (~30 segundos)

✅ Deploy Completo!
O Netlify vai gerar uma URL tipo:
https://seu-site-xyz123.netlify.app

🎮 Abra esta URL e jogue!

🎯 Teste Final

1Abra a URL do Netlify no navegador

2Aguarde conectar

Na primeira conexão pode demorar ~30-60 segundos (servidor "acordando").

3Deve aparecer: "Você: pXXX"

🎉 Sucesso!
Seu jogo está online e funcionando!
Compartilhe a URL do Netlify com seus amigos! 🚀

🐛 Problemas Comuns

❌ "Conectando..." infinito

  • Verifique se configurou WS_SERVER_URL corretamente
  • Use wss:// (não https://)
  • Aguarde 1-2 minutos (servidor pode estar iniciando)
  • Abra o Console (F12) para ver erros

❌ Servidor não conecta

  • Verifique se o deploy do Render completou
  • Abra a URL do Render no navegador (deve mostrar "Servidor Online")
  • Veja os logs no Render Dashboard

⏱️ Demora muito para conectar

  • Normal! Render Free tier "dorme" após 15min inativo
  • Primeira conexão: ~30-60 segundos
  • Conexões seguintes: instantâneas (se houver jogadores online)
